数据存放位置（本机绝对路径）

用途路径

采集产物 = 数据库 + 原始页面 DOM（bronze）+ 轮次 summary + 日志； 登录态/风控状态目录不随数据路径迁移（安全相关）。

自定义数据路径（写 config/paths_override.json；看板与 CLI 同时生效）

必须填写绝对路径；应用后自动建目录、必要时初始化新库，查看历史数据请把 DB 指向已有文件。 CLI 等价命令：run.py paths --set db=… --set raw_root=…（--reset 恢复默认）。

插件设置（脚本自动应用：≤5 分钟或页面刷新生效）

自动模式需v0.5.14扩展的浏览器调试权限，仅操作当前采集页，浏览器会显示调试提示。失败或拼图保留现场；油猴不支持此模式。

扩展支持 1～200 任意整数，只采前 N 个唯一商品；不足时滚动加载更多，连续两轮无新增即停。详情模式复用一个后台标签页逐个采集，标题就绪即读取，无逐商品固定等待。
去重间隔：同一标签页会话内，同一网址成功自动采集后再次自动采集的最短间隔；手动采集不受限制。
SPA 等待：站内路由切换后给页面渲染预留的等待；详情队列不逐张套用。全文请求间隔仅用于列表模式，详情采集间隔仅用于详情页采集（第 2 张起生效），两种间隔相互独立。采集任务内自动按商品编号去重并计数，不会重复采集同一账号。采集进度和取消操作在扩展弹窗中。

网关地址固定为 ；改动网关地址需同步修改用户脚本头部的 GATEWAY 常量。

安装 / 状态

  1. 启动网关：run.py serve（分离后台服务，随本软件自动启动）
  2. 浏览器插件二选一（可同时在 Edge/Chrome/夸克 里各装一份）： 独立扩展——双击「安装浏览器扩展.bat」按引导在每个浏览器加载 pxb7-extension 目录（v0.3.0 起扩展自动更新，无需再手动重载）； 或 Tampermonkey 用户脚本——点此安装/更新 （按 @updateURL 自动检查更新）
  3. 像平常一样浏览 pxb7 的 /buy/* 与 /product/* 页面： 右下角出现「pxb7采集」角标即在工作；扩展为工具栏图标弹窗看板， 油猴版为左下角 📊 按钮面板（采集与状态一体）

通道说明：插件支持列表采集与后台串行详情采集（「每次采集张数」调大时在列表内触发站点自身的 加载更多，等同手动滚动；不猜 URL、不请求站外接口），不受 Playwright 风控退避影响； 拦截页拒收不入库；插件通道覆盖不完整，下架推断固定关闭。
