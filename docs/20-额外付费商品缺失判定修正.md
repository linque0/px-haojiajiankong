# 20 额外付费商品缺失判定修正

> 定位：纠正 v0.5.8 将鸣潮可选付费商品当作必填项的误报。日期：2026-10-07；扩展 v0.5.9。

## 改动

用户确认仅排除“额外付费商品”，其他检测规则保持。统一网关判定不再要求 `vehicle_frame_modules`、`motorcycle_ornaments`、`character_skins` 三键之一存在列表；没有相应段落、字段未采到、NULL、空列表或有实际付费商品都不会单独触发信息不完整。无需重新补录来取得“已核为空”标记。

候选查询、补录准备、完整看板排队、补录后的缺失结果和删除前复核均复用该判定。仅缺付费商品的记录从候选清单移除；旧清单再提交此类记录时拒绝并提示刷新，不启动补录、不备份、不删除。其他必填字段仍缺失的记录保留，只移除付费商品缺失原因。

`coverage` 不再列出额外付费商品；弹窗和完整看板同步显示“额外付费商品允许为空，不计缺失”。鸣潮资源、收藏、区服、发布时间、等级、黄数、五星数量及明细校验保持；其他游戏不变。纠正界面笼统的“可选资源不计缺失”说明，避免与鸣潮现行资源规则冲突。

付费商品解析、展示、CSV 列及原始信息保留，不伪造空列表或零值。本次规则修改不需要迁移、重写数据库或 CSV；历史补录台账保持原记录。docs/19 中付费商品“三键全缺才记缺失”的规则为 v0.5.8 历史口径，当前以本篇为准。
