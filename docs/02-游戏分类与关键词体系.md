## 1. 为什么必须按游戏分类：值钱的东西完全不同

账号不是同质商品，不同品类的"价值锚"差异极大，查证结论：

- **王者荣耀**：V10 贵族等级 ≠ 高价——普通 V10 仅 2000–5000 元，高资产 V10（典藏/限定多）才上万；真正锚点是**荣耀典藏数**（水晶 ≈1600 元/个）与国服战力标（来源：[价值评估全解析](https://www.gc.com.cn/game/ygv10wzhmdsq.htm)、[知乎估价专栏](https://zhuanlan.zhihu.com/p/416583170)）。
- **无畏契约**：皮肤 > 段位——段位每赛季重置贬值，账号价值几乎全压在限定皮肤/近战刀皮上（来源：[估价方法](https://www.sohu.com/a/1079502684_122997382)）。
- **火影忍者手游**：渠道服只有官服 1/3 价；"多个 S 忍"多为话术，**绝版点券 S 忍**才是溢价项（来源：[卖号估价维度](https://www.sohu.com/a/1079465238_122997382)）。
- **原神**：精5五星专武 +300–800 元/把，全图鉴满命满精 2 万起（来源：[账号价值解析](https://www.163.com/dy/article/KL3ENDB70556I6IS.html)、[17173 价格表](https://news.17173.com/z/ys/content/05032023/184827576.shtml)、[知乎](https://www.zhihu.com/question/565052875)）。
- **三角洲行动**：总资产（哈夫币）直接进标题计价，红皮/刀皮/安全箱是结构溢价项；且存在**官方追缴哈夫币**的系统性行情事件（来源：[账号价值拆解教程](https://www.bilibili.com/video/BV1pM9gBKERG)、[估价维度](https://wap.pp.cn/news/1192210.html)、[萌娘百科·梗](https://zh.moegirl.org.cn/zh/%E4%B8%89%E8%A7%92%E6%B4%B2%E8%A1%8C%E5%8A%A8/%E6%A2%97)）。

**推论**：① 估值模型必须**按游戏（同一 genre 内可共享先验）分别建模**；② 单一"等级/贵族等级"特征会误导（V10 反例）；③ 段位类特征要按赛季重置特性降权；④ 词表命中直接决定分域，分域错了回归就被污染。

## 3. 词表框架（dim_keyword）与三个用途

```
dim_keyword(
    keyword_id, profile_id,        -- 挂在哪个游戏画像下
    keyword,                       -- 词/短语，如 '满命' '荣耀典藏' '大红'
    keyword_type,                  -- ceiling 天花板 / floor 地板 / risk 折价 / resource 资源 / segment 分域词
    extract_pattern,               -- 正则（从标题/详情抽取数值），如 '(\d+)命' '精(\d)'
    feature_map,                   -- 命中后写入的估值特征，如 five_star_weapon_refined
    price_anchor,                  -- ceiling / floor / none
    weight_v0,                     -- 初值：来自 §1 资料的相对重要性（人工标）
    weight_v1, weight_v2,          -- 标题挖掘频率 / 模型系数反哺（§7 校准闭环）
    source, enabled, updated_at)
```

**用途**：
1. **搜索切片**——`segment` 词 + 站内筛选器组合成采集任务（如"原神×官服×满命段"任务 = 标题含满命/6命 或 筛选器五星角色≥N）；
2. **属性抽取**——`extract_pattern` 从标题/详情补齐卡片没有的结构化字段（如命座数、精炼等级，列表卡片不直接给）；
3. **价格锚点标注**——命中 ceiling/floor 词的 listing 进入 §6 高价/底价判定的独立定价域（并按 §5 五因子体系归因）。

> **抽取输入口径（2026-10-03 实测补注，用途 2）**：
> - 抽取文本 = 标题 + 卡片字段各值（`listing_text()`，pxb7/extract.py:288-300），并有 [卡] 字段专用通道（pxb7/extract.py:326-338）。实测：`ys_floor_deadmail` 的 8 行命中中 7 行标题不含「邮箱不出售」，命中来自 `fct_listing_snapshot.mail_status` 卡片字段文本 →「[抽]」词条不保证只命中标题。
> - **标题硬截断**：原神列表页 `productname` 属性实测 min=96 / max=160 字符（4 个 2026-10-03 run 逐个数），`dim_listing` 47 条标题（两游戏合计）中 **37 条 length=160**（原神 31 条中 25 条、鸣潮 16 条中 12 条，另 5 条为 159），尾部字段（原石/纠缠之源/邮箱/时装/武器段）常被切掉 → 抽取不能只依赖标题，须按 §4.A1 的 [卡] 字段兜底、武器/尾部字段到详情页取。
> - **2026-10-04 补充：列表悬浮全文优先**：鸣潮列表 `.smallCardTitle` 短文案截断，但悬浮后 `.t-popup .longTitle` 给出完整角色与武器；实测13角色/9武器、23角色/21武器两条明细完整。v0.4.3 自动触发站点悬浮读取并唯一匹配商品，武器无需先进入详情。悬浮会触发站点自身的完整标题请求；详情仅作为未取得全文时的后备。
> - **v0.4.4改进（2026-10-04）**：取消自动悬浮；从公开列表响应 `productBasicInfo.productName` 复用全文，未返回时以卡片 `productuniqueno` 调用同一完整标题接口。`product.CR3wEeEx.js` 的 `getProductTitleByCode` 与 `HotTag.DZXqiZP-.js` 的 `HoverComponent` 证实参数为 `{productUniqueNo}`、成功结果为 `data.showTitle`。明确商品 ID + 短标题前缀校验，不依赖共享弹层。公开标题包含的角色链数/武器精炼仍按既有词表抽取；没有公示的内容保持缺失。
> - [卡]/[抽] 的落地前提是卡片属性可得：2026-10-03 实测原神列表页 `productname` 属性 30 次命中、鸣潮 0 次（鸣潮卡片标题靠类名/文本层回退才拿到），跨游戏「一套属性分支」的假设待实测。

## 5. 跨游戏账号价值体系总纲（五因子模型）

词表解决"每个游戏里什么东西值钱"；本节把它收敛成**统一的五因子分解**，作为估值模型（M2）的特征组织方式和看板白话解读的骨架。每个 listing 的价格 = 五个因子的加权和 × 折价系数，权重由 `feature_profile` 按游戏先验给定、v2 由模型系数反哺校准。

| 因子 | 内容 | 典型词表映射 | 权重特征 |
|---|---|---|---|
| **F1 外观资产** | 皮肤/时装/涂装/车皮的**数量与稀有档位** | 王者荣耀典藏、和平精英限定军需/车皮、无畏契约限定套装、CF 英雄级、永劫金红皮、超自然金皮 | 普遍权重最高；档位内计数，档位间跳变（1 件典藏 ≫ 10 件史诗） |
| **F2 养成练度** | 等级/深渊进度/名望/战力标 | 原神黄数+深渊满星、DNF 名望、王者国服标、三角洲特勤处 | 中等；**受赛季重置惩罚**（见保值性三档） |
| **F3 稀缺收藏** | 绝版/期限定/联动类**不可再生物** | 三角洲大红、崩铁期限定光锥、火影绝版点券 S 忍、APEX 传家宝、光遇绝版季节斗篷 | 单因子溢价最强；随时间**升值或保值**；词表须逐个建条目（数量少、价值集中） |
| **F4 资源存量** | 货币/抽卡资源余额 | 哈夫币/科恩币（直接计价）、原石/星声/菲林/点券/G币 | 可折算；搜打撤类近似"账面价值+溢价率"，其余按抽卡期望价值折算 |
| **F5 安全折价（负向）** | 渠道服/死邮/实名/违规/找回风险 | 见下方折价系数表 | 乘法因子，不进加权和 |

**折价系数表 v0**（乘在五因子加权和上；v0 为人工先验 + 已查证项，v2 由 delist 回归校准）：

| 折价项 | v0 系数 | 依据 |
|---|---|---|
| 渠道服 | ×0.3–0.4 | 火影渠道服 ≈ 官服 1/3（查证） |
| 死邮/邮箱不出售 | ×0.6–0.8 | 原神"活邮"显著溢价（查证），死邮取下沿 |
| 无法换绑/绑定限制 | ×0.7 | 无畏契约绑定折价（查证），跨游戏先验 |
| 违规记录 | ×0.5 或不收 | 无畏契约查证 |
| 实名不可改 | ×0.7–0.85 | 崩铁"能否二次实名"核查项（查证），待校准 |

> **本地可校准性（2026-10-03）**：本地 52 条快照 `server` 全部为「官服」（52/52），「渠道服」「国际服」两条 seed 词在 47 条标题与卡片字段上 0 命中 → 渠道服系数**无本地样本可校准（待实测）**；「死邮/邮箱不出售」在 `fct_listing_keyword` 有 8 行命中（其中 7 行来自卡片字段 `mail_status` 文本，非标题），可进入 v2 回归，但 v0 系数仍为查证先验。

**保值性三档**（决定 F1/F2/F4 特征的时间衰减处理与 M7 分层）：

1. **绝版收藏档**（F3 为主）：随时间保值/升值——趋势分析单独分层，不做折旧；
2. **永久外观档**（F1 为主）：缓释贬值（版本迭代稀释相对稀缺度），半衰期按年计；
3. **赛季重置档**（F2/部分 F4：段位、赛季资源、战阶）：快速贬值，估值为 0 或按重置后价值计——无畏契约/和平精英查证均确认"段位是弱特征"。

**归因输出**：每个 listing 的估值报告按五因子分解给出"值在哪"（如：F3 一件期限定 +F1 十件史诗 − F5 死邮折价 → 预测价 X），对应看板"白话诊断"与捡漏雷达的归因明细。这也是对竞品"估价口径不透明"（逆战未来查证原话："说不清是按战阶、枪皮清单还是载具改装折算"）的直接差异化。

## 6. 高价/底价判定体系（双层，输出 price_band）

**第一层：统计层（模型驱动，主判定）**
- 在 **游戏 × 区服 × 价格段** 子域内跑 M2 hedonic 回归 → 预测价 → 残差 = ln(实际价/预测价)；
- 子域内残差分位映射价格带：`≤P10 底价带(floor) / P10–40 偏低(low) / 40–60 合理(fair) / 60–90 偏高(high) / ≥P90 高价带(ceiling)`；
- 子域样本 <30 不发布（沿用"不伪造"原则）；分段原因：100 元号和 2 万元号的定价逻辑不同，跨段回归必被天花板号拉偏。

**第二层：锚点层（关键词驱动，分域与修正）**
- **ceiling 词命中**（如荣耀典藏≥1、大红、绝版点券 S 忍、满命 UP≥2）→ 划入"天花板域"单独定价：这类号的溢价由词表驱动的稀缺性决定，留在普通域会污染回归；
- **floor 词命中**（初始号/自抽号/死邮/渠道服）→ 应用折价因子或划入"地板域"；渠道服类（火影渠道服 1/3 价）**强制分域不混算**；
- ceiling 与 floor 同时命中 → 取更极端者，并打 `manual_review` 标记。

> **⚠ v0 已知偏差（2026-10-03 实测，直接影响第二层）**：原神 `ys_ceiling_jingwu` 25 行命中中仅 2 行是真「精5」、`ys_ceiling_manming` 35 行命中中 22 行是 1–5 命——两条都带 `price_anchor=ceiling`，会把大量普通号误划入天花板域（详见 §4.A1「实测命中质量」）。v1 收窄前，第二层的 ceiling 分域结果**只作观察不作定价**；鸣潮 v0 已吸取该教训（满命/N命 只记计数、不进锚点层，见 §4.A4）。

**输出**：每个 listing 标注 `price_band ∈ {floor, low, fair, high, ceiling}` + **归因明细**（命中词表 + 贡献最大的特征）+ 更新后的 deal_score（捡漏信号只从 floor/low 带出，high/ceiling 带只做趋势观察不做捡漏推荐——避免"贵的东西打折"误报）。
