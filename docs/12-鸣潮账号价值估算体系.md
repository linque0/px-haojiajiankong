# 鸣潮账号价值估算体系 v1.0

> 定位：用当前账号样本建立可审计的挂牌参考估值与人工估价流程。日期：2026-10-05（Asia/Shanghai）。
> 本次方案已先在聊天中给出，再执行研究、建模与验证。附件与网站内容仅作为证据，未当作用户指令。

## 1. 结论与使用定位

已建立“配置清单 → 字段审计 → 同市场价格模型 → 参考区间 → 可比号 → 人工核验”的体系，并生成逐账号结果。**v1.0预测的是这批 pxb7 官服账号的挂牌参考价，单位人民币；实际成交价值暂不能估计。**

当前294个账号中，285个通过本次字段/区服门槛，9个保持待复核；在285个分组留出预测中，5个存在训练配置外推，单独进入人工估值。其余280个可作为普通价格筛查样本。声骸、技能、地图、实名/绑定、违规记录和交割条件未在CSV中提供，因此所有账号的完整价值判断仍存在关键缺口。

独立测试的中位绝对百分比误差为31.1%，平均绝对误差为411.83元。该水平支持筛查和人工估价辅助，不能支持保证回收价、保证成交价或自动购买。结果中的“低于参考带”仅为进一步核验线索。

## 2. 已执行方案

1. 冻结指定CSV的来源路径与SHA-256，保留原文件。
2. 审查账号ID、区服、价格、字段完整性，重建角色/武器份数，对齐黄数口径。
3. 经Exa分三个方向检索：鸣潮机制与官方规则、鸣潮估价、其他热门二游估价。11次搜索返回66个候选URL，重点读取12个不同URL的正文；其中两个Wiki路径属于同一资料，不算独立证据。
4. 构建资产与条件维度，拆出重复计价风险和未知项；网页固定人民币系数不直接进入模型。
5. 比较价格中位数、仅黄数、结构特征、名称细分四类模型；模型和正则强度只用训练集合内部交叉验证选择。
6. 固定配置分组的训练/校准/测试，并另做五折嵌套分组留出，为本批账号输出不含自身价格训练的估值。
7. 交付规则、程序、模型、逐号估值、可比号、字段审计、来源登记与验证结果。

### 5.1 份数、黄数与去重

设角色链数为 `c_i`，第j件武器精炼为 `r_j`：

```text
角色本体数 = 不同角色名称数
角色份数 = Σ(1 + c_i)
武器件数 = 武器明细条目数（同名多件保留）
武器份数 = Σr_j
重建黄数 = 角色份数 + 武器份数
```

这里是从库存重建的口径，不等于历史实际抽到五星次数；赠送、自选、商店兑换可能改变获取成本。

“0链”已有1份角色，“6链”对应7份角色。精1是一件/一份，精5是一件/五份；两把同名精1是两件/两份。角色重复名字标记冲突，不按多个角色相加。**黄数只在独立基准模型和质量校验中使用，细分资产模型不额外加入黄数收费项。**

### 5.2 资源折算与机会成本

参考[GameKee卡池机制](https://www.gamekee.com/mc/622060.html)的单位规则：

```text
已列示灵活抽数 = (已列示星声 + 已列示月相) / 160
已列示角色券 = 浮金波纹
已列示武器券 = 铸潮波纹
珊瑚抽券等价 = 已列示余波珊瑚 / 8
```

这只是抽数等价，不是人民币单价。浮金与铸潮分别保留；常驻券不与限定券等价。CSV全未列唤声涡纹，本次无法识别它的独立价格效应。

余波珊瑚可有兑换频段的其他用途，未来人工估价按账户持有、当期可换和限购状态比较可实现的替代用途，**选择其一，不把珊瑚抽数价值和将要兑换的链数价值同时加上**。未领取地图奖励、未来月卡领取和保底价值也要有截图和状态，不凭描述补数。Wiki为机制辅助依据，当前游戏内截图仍是余额和规则确认的必要材料。

### 5.3 完整价值的扩展模型

完整目标分为三项，禁止混用：

1. **市场挂牌参考价 `P_list`**：本次已建模，回答“当前同市场类似配置如何挂牌”。
2. **实际成交价 `P_sale`**：待获得已核验成交样本，按同平台、区服、配置、日期和持有期重新训练；不以固定80%估算。
3. **卖方净到手 `P_net`**：`P_sale - 已确认手续费 - 已确认保障/交接等费用`；费率未知则保持未知。

人工收号决策还需对交接失败、被找回、违规封禁、资金占用和售后可兑现程度形成单独情景。可以表示为收益和损失的条件加权，但概率和金额须来自可核对记录；本次不产生定量安全折扣。

## 6. 当前模型、公式与验证

### 6.1 可复算公式

```text
log(P_list) = b + Σ β_k × z_k
z_k = [transform(x_k) - 训练均值_k] / 训练标准差_k
P_list = exp(log(P_list))
```

数量类主要使用 `log1p` 表示边际递减；追加链数、链数阈值人数和联觉等级线性输入。缺失项用训练集合统计填补，并保留缺失指示。岭回归约束为 `alpha × Σβ²`，抑制小样本名称特征过拟合。候选alpha为1、10、100。

选中“名称细分”模型，alpha=100，172个训练账号，131个特征。包含聚合资产、出现频次达到门槛的角色持有/链数与武器份数；**名称筛选和标准化均仅在相应训练集合上完成**。测试挂牌价、商品ID、收藏、发布时间不作为预测输入。收藏会受报价、曝光和上架时间影响，不把它当独立资产价值。

131个相关特征对172个训练样本而言仍偏多，因此强收缩是必要限制。系数可解释为条件相关的log价格项，不能解释成角色/武器的人民币独立售价，也不能据符号推出真实因果或强度榜。模型未强制单调；新增资产可能因相关系数而出现不合理边际变化，这时应人工复核，不把它用于自动资产收购。

### 6.2 独立测试结果

按配置指纹分组，训练172／校准57／测试56。训练内部四折分组CV仅按log MAE选模型；测试集合只报告结果，不据测试结果再选超参数。

| 模型 | 独立测试中位APE | MAE（元） | ±30%内比例 | log MAE |
|---|---:|---:|---:|---:|
| 训练价格中位数 | 58.2% | 591.86 | 30.4% | 0.762 |
| 仅黄数 | 44.6% | 459.02 | 33.9% | 0.521 |
| 分组结构特征 | 36.4% | 651.12 | 44.6% | 0.458 |
| 名称细分（选中） | **31.1%** | **411.83** | **50.0%** | **0.382** |

APE=`abs(预测价/挂牌价-1)`。MAE受到高价账号大误差影响，故同时报告各价位可比的log MAE和中位APE。结构模型的MAE高于简单基准，说明增加维度不保证每项误差更小。

### 6.3 两种区间不能混用

**新配置预测模型**：保留只在172个训练账号拟合的 `model.json`，以57个校准账号的绝对log误差的有限样本80%顺序统计量为半径；`q=0.599565`，预测带为 `[P/1.82133, P×1.82133]`。独立测试56个账号中46个落入此带，覆盖率82.1%。这只是名义80%的同分布预测带；真实卖家组未知、同卖家相似号或版本变化会破坏覆盖前提，不能承诺未来覆盖率。

**当前285个账号的批量筛查**：每个外层折内重新进行模型选择，使账号及相同配置不进入自己的训练集合。五折全体OOF中位APE=26.9%，MAE=329.73元。OOF误差80%经验半径 `q=0.579684`，参考带为 `[P/1.78547, P×1.78547]`。该带由本批OOF误差描述而来，**不是独立校准的置信区间，不具备未来覆盖保证**。

新账号预测遇新名称、极端范围或非官服时暂停报价，给复核标记。本批表仍保存外推计算值供审计，但5个外推账号禁止使用“低价线索”分流。模型未在全部285行上再拟合，从而保留独立校准与测试的清楚边界。

## 7. 市场规律与估价操作

以下为285个有效官服挂牌的描述性分组，**不能解释成控制其他条件后的单件增值**：

| 非基础常驻6链人数 | 样本数 | 挂牌中位数 | P25–P75 |
|---|---:|---:|---:|
| 0 | 129 | 340元 | 230–550元 |
| 1 | 95 | 530元 | 282.94–800元 |
| ≥2 | 61 | 1,688元 | 1,200–2,330元 |

每个价位仍有很大配置差异，这支持“看名称、链数、资源与完整度”，但不支持“每个满链统一加价”。黄数≤30／31–50／51–70／>70的挂牌中位数分别为190／350／600／1,231.50元，也只能作为粗分层。

### 7.1 人工操作顺序

1. 核实区服、账号可交接条件与违规记录；无法确认时估值注明条件，不给可兑现保证。
2. 对照游戏内角色/武器页，检查名字、链数、同名武器、多件精炼和库存份数。
3. 输入资源实际余额，包括明确的0；未展示保持空，不把未领取奖励混成余额。
4. 检查声骸、技能和可独立出战的队伍，核对配套武器；标记哪些“毕业”仅是卖方话术。
5. 查 `账号估值结果.csv` 的关系与支持标记，使用5个可比账号ID回看配置。可比号按结构距离选择，排除自身与同配置组；不宣称完全同配。
6. 价格落在参考带外先解释差异：交接限制、免费资产、配置稀缺、练度、促销/急售、字段错漏；没有解释就先补证据。
7. 只有取得成交与手续费证据后，才形成成交和净到手估算。

本次结果分流：227个参考带内、26个低于参考带待核验、27个高于参考带待复核、5个外推人工估值、9个字段/区服待复核。26个低价线索不是推荐购买名单。

### 7.2 示例与外推限制

账号 `2432787509084913264` 挂牌6,000元，分组留出模型计算约21,004.80元，但其满链人数和追加链数超出该折训练范围，并且预测高于训练集合最高挂牌。这一账号被标记“外推/新名称：人工估值”，不能据此声称低估15,000元。这个例子说明保留模型支持检查比只展示精确数值更有用。

## 8. 后续采集规范与更新机制

下一版优先补四类数据：

1. **价格结果**：真实成交金额、订单状态、成交日期、费用；下架不等于成交。
2. **交接条件**：仅采集是否可换绑、材料是否齐全、冷却天数、绑定类型、已核实违规/找回记录等状态，不收集身份证号码、原手机号或邮箱地址。
3. **养成与战斗体系**：角色技能、声骸套装/词条、可验证挑战记录、独立队伍及装备冲突。
4. **纵向快照与事件**：同号同价时间序列、官方版本/赠送/复刻事件，区分采集时间、上架时间、成交时间。
