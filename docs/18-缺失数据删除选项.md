# 18 缺失数据删除选项

> 定位：扩展查缺补录的人工数据清理与 CSV 同步。日期：2026-10-06；扩展 v0.5.7。

> 2026-10-06 更新（v0.5.8，[docs/19](19-完整看板查缺补录与下架检测.md)）：删除成功后清单即时移除已删行并强制刷新（不再等待 10 秒自动刷新，修复刷新被重入锁吞掉的问题）；整批拒绝时自动强刷、清空旧选择并明确提示"未删除任何数据"。删除入口同步加入完整看板区块。

## 改动

用户确认删除范围为“选中商品全部入库轮次”。本次仅提供操作入口，未替用户删除现有数据。

1. 弹窗“信息查缺补录”增加“勾选本页补录失败／未补齐”和“删除选中”。快捷勾选仅匹配当前快照的失败或仍有缺项结果；其他无法补录的缺失商品可人工勾选，包括尚未启用采集目标的游戏。已完整商品不在查缺清单，服务端也拒绝删除。
2. 保留跨页选择；每次最多删除 200 个商品，不提供自动删除或一键删除全部。确认框列出商品编号，明确删除全部轮次及关联数据、备份和恢复影响。刷新发现新轮次时清除旧选择，服务端再次校验快照与缺失状态；任一目标过期或已补齐，整批拒绝。
3. 扩展仅允许 `popup.html` 发出固定 `backfill-delete` 消息；固定网关 `POST /backfill/delete` 拒绝站点 Origin，参数只接收已选商品编号与完整快照时间，不接受网址、SQL 或文件路径。后台将删除与采集开始串行，运行中／等待验证时必须先取消采集。
4. 在网关状态锁和项目锁内执行 `CHECKPOINT`、关闭连接、备份至数据库同级 `backups/delete-backfill-时间戳.duckdb`。备份失败不启动删除。事务清理商品维表、全部快照、关键词命中、价格变动、下架记录及物化关键词矩阵；失败整体回滚。成功后清除对应待入库详情缓存和扩展最近补录记录。
5. 删除提交后逐游戏调用 `sync_game_csv`，更新 `F:\deepseek workplace\pxb7-price-monitor\data\analysis\by_game` 对应原 CSV，保留文件名、列布局和 UTF-8 BOM。最后一个商品删除后，原 CSV 保留表头并清空数据；修复空游戏名称导致另建数字名文件的问题。CSV 占用失败保留数据库删除结果及旧文件，展示受影响游戏、原因，并复用“重试同步数据表”；重试支持当前已无商品的已注册游戏。

## 使用

1. 应用扩展更新到 v0.5.7，重新打开弹窗。
2. 在信息查缺补录区域按游戏筛选。点击快捷勾选选中本页失败／未补齐记录，或手动勾选确定无法补录的商品；翻页可以累积选择。
3. 点击“删除选中”，核对商品编号及全部轮次范围，再确认。仍在采集或等待验证时先取消任务。
4. 查看删除商品／快照数量、CSV 同步状态及备份路径。若表格被占用，关闭该文件后点击“重试同步数据表”，无需再次访问详情页。

删除针对当前数据库，不删除原始采集 HTML、运行日志及历史备份。后续重新采集同一商品或重放原始页面可能重新入库。本功能不维护永久屏蔽名单。

## 恢复备份

没有一键撤销。若需要恢复，应先取消扩展采集并停止网关／其他数据库写入进程；另存当前数据库，再将删除提示中的 `.duckdb` 备份复制到配置指向的数据库路径。不要在数据库打开时替换文件，也不要把较新数据库的 WAL 文件配到旧备份上。重启后重新导出受影响游戏 CSV。

备份恢复是整库恢复，会回退删除之后的其他数据库改动。需要保留后续数据时应单独提取并审核被删商品的关联记录，再事务恢复，不能直接覆盖数据库。

## 验收

- 临时库回归覆盖：选中商品全部轮次及关联事实清理、其他商品原数据保留、未启用目标仍可删除、备份可读、备份失败不删、事务失败回滚、未确认／重复／空／超过 200 个选择拒收、旧轮次和已补齐商品拒收。
- CSV 回归覆盖：单商品删除后原表仅保留其他商品，删除最后一个商品后原日期文件清空且保留表头/BOM，文件占用失败保留旧表，游戏无商品时可重试同步。
- 实际后台脚本回归覆盖：内容脚本删除消息拒收、采集中拒删、删除与新任务串行、删除成功清理指定补录结果并保留其他结果、同步失败进入已有待同步状态。
- 实际 `popup.js` 的离线 Node DOM 回归覆盖：失败／未补齐快捷勾选，排除旧轮次结果，未启用游戏的删除与补录按钮行为，取消确认不请求删除，跨页提交及结果显示，新轮次清除选择。
- HTTP 回归覆盖：固定删除端点校验来源、确认和参数，临时库实际删除成功及空游戏 CSV 同步。

最终结果：全量离线回归 **393 通过、2 跳过**（307.57 秒）。随后增加实际弹窗 Node 回归并调整删除后的同步结果文字，相关最终回归 **11 通过**（15.59 秒），涵盖 4 项数据库删除用例和 7 项扩展脚本用例。

本机网关已加载新代码，后台进程 PID 54728。用空请求检查实际 `POST /backfill/delete`，返回 HTTP 400 `delete-confirmation-required`，未发起有效删除。重启及接口检查前后生产库均为 **704 条快照、639 个商品，挂牌价格总和 595157.76**；本次没有对生产数据执行删除、补录或恢复。

## 诚实边界

所有删除行为验收使用临时数据库或模拟清单，未删除生产数据。真实扩展弹窗受浏览器工具访问限制，使用普通本地 HTTP 离线预览实际弹窗代码；已观察到失败记录与新增按钮，快捷勾选后的“删除选中（2）”可用。原生确认框显示后控制工具超时，未完成浏览器确认／取消后的界面实测；相关行为由实际 `popup.js` 的 Node DOM 回归覆盖，不能声称真实扩展已现场点击删除。未新增站点请求、未采集商品、未绕过网站验证，未替用户恢复生产备份。
