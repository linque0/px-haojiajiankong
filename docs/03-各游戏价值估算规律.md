# 03 各游戏账号价值估算规律（价值体系构建底稿）

> 版本 v0（2026-10-02）。定位：逐游戏推理"这个游戏的账号**为什么**值钱、值多少、**怎么算**"，
> 为 M2 估值模型（docs/01 §5）的特征设计、分段切分、交互项与折价层提供依据。
> 每节统一六段式：**定价逻辑推理 → 估值算式骨架 → 因子画像（F1–F5，docs/02 §5）→ 分段与交互 → 陷阱与话术 → 数据可得性**。
> 依据：docs/02 §4 词表及其查证来源（2026-10-02）；标注（先验）的数字为公开资料量级参考，不作硬编码价格；标注（待校准）为领域知识，接入时查证。

## 0. 总纲：三类资产定价机制与八条共性规律

任何游戏账号 = 三类资产的组合，**三类资产的定价机制完全不同**，这是价值体系的总纲：

| 资产获取方式 | 定价机制 | 例子 |
|---|---|---|
| **direct 直购型**（充值直购、可查账） | 账面折算法：价格 ≈ 直购价 × 折扣率（0.3–0.7） | CF 英雄级武器、无畏契约辐能、点券类余额、鸣潮星声 |
| **pity 概率抽取型**（抽卡保底） | 期望成本法：价格 ≈ 期望抽取成本 × 折扣（30–50%）+ 强度/人气修正 | 原神满命、王者典藏（水晶）、鸣潮 6+1 |
| **discontinued 绝版型**（不可再获取） | 供需定价法：价格由存量持有者与需求决定，随时间保值或升值 | 三角洲大红、崩铁期限定光锥、火影绝版点券 S 忍、光遇季节斗篷、APEX 传家宝（半绝版） |

**八条共性规律**（后文逐游戏验证）：
1. **档位跳变律**：同档位内计数近似线性，跨档位跳变（1 件典藏 ≫ 10 件史诗）——线性回归必须分段或加交互项；
2. **同捆专用性律**：角色与专属武器/装备绑定产生溢价（绝区零音擎+角色同捆 +20% 查证）；
3. **安全折价普适律**：活邮/死邮、渠道服、实名可改性、违规记录——跨游戏一致的风险定价，渠道服最狠（火影 1/3）；
4. **赛季贬值律**：段位类资产估值 ≈ 0（无畏契约/和平精英查证"段位是弱特征"）；强度标有维护衰减（王者国服标转手必掉）；
5. **流动性定价律**：绝对价位由用户盘与交易流动性决定（鸣潮 ≈ 原神同配置的 1/5–1/10；渠道服 1/3）——**系数禁止跨游戏/跨区服迁移**；
6. **事件敏感律**：追缴（三角洲哈夫币）、复刻/返场（光遇、第五人格）、免费发放（异环零成本满命）、赛季重置——直接改变资产价值，必须进事件库；
7. **话术陷阱律**："多个S忍""全图鉴（含常驻）""自带价""仓库科恩币 vs 头顶科恩币"——抽取器内置反话术规则；
8. **强度梯队律**：二游/竞技游戏的溢价向 T0 梯队集中（鸣潮卡提希娅/弗洛洛），梯队随版本变动 → 角色人气词表周更。

## 1. 二游抽卡系（gacha）

### 1.1 原神（10026）——"收藏矩阵 + 资源折算"型，全体系模板

**定价逻辑推理**：账号价值分三层。**收藏层是主体（约 70–85%）**：角色 × 专武构成二维收藏矩阵，角色价值 = 人气 × 强度梯队 × 命座数，命座价值非线性（6 命是质变不是 +16.7%）；专武与角色强绑定——"专武没人用"的价值远低于"角色在用的专武"，这就是同捆专用性（交互项的证据）。**资源层**（原石/纠缠之源）按抽卡期望价值打折折算（原石只能用于抽卡 → 折扣率 0.6–0.8）。**练度层**（圣遗物/等级）不直接计价——圣遗物词条随机且不可交易，只能作为 ±10–20% 的加成项；查证锚点"精5专武 +300–800 元/把"正是练度/收藏边界的例子（精炼是武器属性，可标准化）。风险层普适：活邮（可换绑邮箱）显著溢价、死邮折价、国际服分域。

**估值算式骨架**：
```
预测价 = Σ(人气角色 × 命座系数) + Σ(专武 × 精炼系数) + 资源存量 × 0.7
         + 练度加成(±15%) + 图鉴跳变项
         × 活邮系数 × 区服系数
关键跳变：全角色图鉴（6–7k 起）｜满精矩阵（2w 档）｜人手精5专武（5–6w 档）——查证先验
```

**因子画像**：F3 稀缺收藏 > F1 外观（时装仅次要）> F4 资源 > F2 练度；保值档：角色/专武 = 永久外观档偏上（角色可复刻但命座限时机不常见）。

**分段与交互**：价格段切分点 = 是否全图鉴、是否含 T0 限定；交互项 = 人气角色 × 专武（同捆）、原石 × 纠缠（资源等价折算）。

**陷阱与话术**："全图鉴"话术常含常驻五星（含金量骤降）；埃洛伊不计；初始号/自抽号是地板词且有封号风险（工作室批量注册）；"UP 角色"不写命座默认 0 命。

**数据可得性**：卡片直接给黄数/五星角色数/五星武器数/原石/纠缠/圣遗物 [卡]——**全体系结构化最好**；命座/专武归属需标题抽取 [抽]。

### 1.2 崩坏：星穹铁道（10161）——同构，但"绝版武器 + 记法标准化"

**定价逻辑推理**：与原神同构（星魂↔命座、光锥↔专武、遗器↔圣遗物），三点差异改变规律：① **期限定光锥卡池结束后绝版**——查证"满叠影限定五星光锥带来数百元溢价"，光锥的绝版属性使 F3 占比高于原神（原神专武常驻复刻）；② **0+1 记法标准化**（星魂数+专武数）→ 全体系抽取最规整的市场，模型首选试验田；③ 光锥池无大保底定轨 → 获取成本低于原神专武 → 折价率与原神不同，**禁止迁移系数**。

**估值算式骨架**：
```
预测价 = Σ(角色 × 星魂) + Σ(期限定光锥 × 叠影 × 绝版系数) + 遗器毕业度 + 星琼/专票 × 0.7
         × 二次实名系数（硬门槛，查证核查项） × 区服系数
```

**因子画像**：F3（期限定光锥）↑ > F1 收藏 > F4 > F2；混沌回忆/虚构叙事满星 = 练度证明（加成项）。

**分段与交互**：记法正则 `(\d+)\+(\d+)` 直接产出两个特征；交互 = 角色 × 专属光锥。

**陷阱与话术**："满魂"专指星魂 6 层；光锥"1 阶满精"与"5 阶满叠"差数倍——抽取必须读叠影数。

**数据可得性**：卡片字段结构待接入时实测；标题记法标准化高 [抽]。

### 1.3 绝区零（10312）——"宠物子市场 + 同捆溢价"型

**定价逻辑推理**：三槽位（影画/音擎/驱动盘）同构二游，两个独有规律：① **邦布是唯一有独立宠物子市场的二游**，且有公开分档价（单 S 8–20 / 3S 成套 30–50 / 5S 满配 80–150）→ 宠物因子可独立建模；② **音擎+角色同捆 +20%**（查证）→ 专用性溢价的直接可量化证据。查证特别警告"**只数 S 角色数量会显著低估**"——S 与 S 之间的价值差远大于常驻/限定之差，特征必须按"限定 S × 人气梯队"加权而非计数。驱动盘词条随机性是二游里最大的 → 毕业度只能用"毕业件数"近似，不能像崩铁遗器那样精细。

**估值算式骨架**：
```
预测价 = Σ(限定S代理人 × 影画 × 人气系数) + Σ(专属音擎 × 精炼) + 同捆加成(+20%/对)
         + 邦布分档价 + 驱动盘毕业件数加成 + 菲林 × 0.7 × 绑定系数
```

**因子画像**：F3 > F1（音擎）> F4 > F2；式舆防卫战进度 = 练度证明。

**分段与交互**：核心交互 = 代理人 × 专属音擎（同捆）；分段切分 = 是否含当期 UP。

**陷阱与话术**：常驻 S ≠ 限定 S；"满配邦布"要数 S 数；绳网等级 ≈ 账号时长（弱信号）。

**数据可得性**：卡片字段待实测；报价先验（看个号）可做 sanity check。

### 1.4 鸣潮（10302）——"低绝对价位 + 强度梯队主导"型

**定价逻辑推理**：绝对价位是原神的 1/5–1/10（0 命热门限定 25–35 元 vs 原神同配置数百元），推理原因有三：① 用户盘与交易流动性小（流动性定价律）；② 官方赠送慷慨（版本送抽多）→ 自抽期望成本低 → 账号溢价空间被压缩；③ 玩家"抄作业"文化使强度导向极强 → **溢价向 T0 梯队集中**（卡提希娅/弗洛洛/今汐），人气词表要按强度榜而非泛人气维护。声骸背包 3000 满 = 长期囤积玩家信号（时间资产溢价）。

**估值算式骨架**：
```
预测价 = Σ(限定共鸣者 × 共鸣链 × T0系数) + Σ(专属武器 × 谐振) + 声骸毕业度 + 星声 × 0.7
         × 渠道服系数
参考梯度（先验）：0命 25–35｜0+1 45–60｜2+1 80–120｜6+1 满链 220–320（热门限定）
```

**因子画像**：F1 收藏（T0 加权）> F3 > F4 > F2。

**分段与交互**：交互 = 共鸣者 × 专属武器（0+1 记法）；**严禁跨游戏迁移原神系数**。

**陷阱与话术**：同 0+1 记法；"满链"= 6 链；渠道服分域。

**数据可得性**：卡片字段待实测；记法抽取成熟（与崩铁共用正则）。

### 1.5 异环（10630）——"事件驱动估值"的典型教材

**定价逻辑推理**：新游，价格发现未完成 → 波动大、样本少。最有价值的规律是查证发现的**官方免费发放满命 S 角色（"零成本满命"）事件**：该角色的命座市场价值被系统性压为 ≈0——证明"获取途径"本身是估值特征（pity 成本为 0 的资产不产生溢价）。这是全体系"获取途径特征（direct/pity/free）"的最佳案例。满命全图鉴成交 1200–1500 元（查证）→ 绝对价位锚极低（测试期资产 + 市场未成熟）。

**估值算式骨架**：二游通用模板 + `free_grant` 事件降权项；样本门槛从 30 提高到 50；阶段判定只观察不推信号。

**因子画像**：F3 > F1 > F4 ≈ F2；时装/载具/通行证是查证确认的锚点。

**陷阱与话术**：测试期资产（测试资格本身曾是资产）随公测贬值——时间衰减特殊。

**数据可得性**：卡片字段待实测；词表 source=template 低置信。

### 1.6 明日方舟：终末地（10605）——"开服价格发现"期

**定价逻辑推理**（查证）：核心价值锚 = **干员配置质量 × 武器（战术装备）构筑**——六星干员数量、潜能（重复抽取）、专精等级、限定池角色决定基础价；基建等级/效率是时间成本资产（鹰角系游戏的特色：基建是挂机收益引擎）；资源存量折算；区服溢价调整。换绑依赖鹰角通行证系统 → 换绑安全性是平台验号重点（风险层）。明日方舟 IP 的历史规律（端游前作）：老账号因绝版干员而升值——终末地是否复现**待验证**（开服期价格发现波动大）。

**估值算式骨架**：二游通用模板（干员×潜能、武器×精炼）+ 基建效率加成项 + 资源折算 × 通行证换绑系数。

**因子画像**：F3 > F1 > F2（基建）> F4。

**分段与交互**：干员 × 专武交互；限定池角色分档。

**陷阱与话术**：开服期"开局号/初始号"供给大 → 地板价波动剧烈；交易猫验号报告覆盖不全（基建/专精需卖家截图）→ 我们卡片抽取的差异化点。

**数据可得性**：卡片字段待实测（新游，筛选器可能未完善）。

### 1.7 遗忘之海 / 诡秘之主——观察组

诡秘之主（快手发行，上线初期，查证确认无成熟估价体系）：通用二游模板 + `source=template` 低置信；IP 序列/非凡者概念可能构成角色梯队词——待标题挖掘。遗忘之海：同理观察。**规律**：上线 6 个月内的新游只做供给/价格监测，不做估值输出（样本与价格发现都不足）。

## 2. 搜打撤资产型（extraction）

### 2.1 三角洲行动（10371）——"资产组合折算 + 隐含汇率"型

**定价逻辑推理**：账号 ≈ 资产组合：**价格 ≈ 哈夫币 × 隐含汇率 + Σ物资 × 折算价 + Σ不可购买物品溢价 + 结构加成**。隐含汇率存在的原因：官方有充值通道（曼德尔砖等），玩家间又有转账需求但受限 → 供需形成灰色汇率——汇率本身是 M7 的时间序列研究对象（查证有"S11 赛季 2 亿哈夫币能换多少钱"这类公开讨论）。**大红/红皮不可直接购买** → 纯供需定价（discontinued 机制），溢价率最高。特勤处/仓库等级 = 时间资产（挂机/任务积累）。**系统性风险**：官方追缴哈夫币（萌娘百科记录 S4 前追缴事件）→ 资产型账号独有的持有风险 → 折价与汇率跳变，进事件库。**重复计价警告**：外观（枪皮/刀皮/干员皮）常被计入"总资产"标题数字里 → 回归用增量形式（资产额 + 外观增量项），避免 double counting。

**估值算式骨架**：
```
预测价 = 哈夫币 × 隐含汇率(t) + Σ物资折算 + Σ大红/限定外观溢价 + 安全箱/特勤处加成
         × 追缴风险系数 × 绑定系数
外观项用增量回归（资产额已含部分皮肤价值）
```

**因子画像**：F4 资源（主导）> F3（大红）> F1（外观）> F2（特勤处）；保值档：哈夫币跨赛季保留（部分重置）→ 中高保值，但受追缴事件冲击。

**分段与交互**：按"资产额分段"（千万/亿级）切分——资产型账号跨段线性假设失效；交互 = 哈夫币 × 赛季阶段（季末抛压）。

**陷阱与话术**：标题"总资产 16774.74M"的 M/W 单位解析；"大红"与"红皮"混用；资产截图真伪（平台验号解决，我们如实记录 collected_via）。

**数据可得性**：卡片给干员皮肤/枪皮计数 [卡]；哈夫币/总资产需标题抽取 [抽]。

### 2.2 暗区突围（10110）——同构，"仓库硬资产"口径

**定价逻辑推理**（查证五维度口径一致）：**"不看等级战力，看仓库硬资产"**——仓库资产总值（科恩币、大金、钥匙）、装备储备（满改枪/金枪械/金色套装/安全箱格数）、稀有涂装、养成进度（次要）、绑定可转移性。与三角洲的机制差异：① **科恩币有两形态**（仓库物资形态 vs 持有余额），流动性不同 → 抽取必须区分，折算率不同；② 满改枪有战损逻辑（对局损耗）→ 仓库囤积的满改枪按"可立即使用"溢价；③ 大金 = 高价值可交易物资 → 物资层定价主体。

**估值算式骨架**：
```
预测价 = 科恩币(余额 × w1 + 仓库物资 × w2) + 大金/钥匙折算 + 满改枪/金装套数 × 单价
         + 限定涂装溢价 + 安全箱格数加成 × 绑定可转移系数
（w1 > w2：余额流动性高于物资形态）
```

**因子画像**：F4 主导 > F3 > F1 > F2。

**分段与交互**：与三角洲同（资产额分段）；交互 = 科恩币 × 赛季阶段。

**陷阱与话术**：仓库科恩币 vs 头顶科恩币（查证明确）；"大金"范围随版本变动。

**数据可得性**：卡片字段待实测；查证先验（看个号五维度）可做 sanity check。

## 3. 皮肤计数/档位型

### 3.1 王者荣耀（10013）——"档位跳变 + 强度衰减"型

**定价逻辑推理**：皮肤档位价值跳变全体系最陡：史诗（几十元）→ 传说（百元级）→ 星传说（数百）→ **荣耀典藏**（水晶抽取成本 ≈1600 元/个，查证）。典藏的估值锚是**期望获取成本**（pity 机制）→ 市场价 ≈ 成本 × 折扣。**V10 陷阱的推理**：贵族等级 = 历史充值累计 ≠ 现存资产——充值可能消耗在抽奖/道具/失败获取上，不留存为可展示资产；查证"普通 V10 仅 2000–5000，高资产 V10 才上万"→ 模型只允许"现存资产计数"进特征，贵族等级最多做先验。**国服/国标的衰减推理**：战力标需要每周维护（打排位保持排名），转手后买家未必维持 → 标的价值按"维护衰减"快速折价——与绝版收藏（F3）的保值方向相反，是 F2 的极端反例。安卓 Q 区溢价 = 流动性定价律（买家基数大 + 转移路径成熟）。

**估值算式骨架**：
```
预测价 = Σ荣耀典藏 × 水晶成本 × 折扣 + Σ星传说/热门传说 × 档位价 + 稀有英雄（武则天等）
         + 全英雄跳变 + 国服标 × 衰减系数(t) + 巅峰赛分 × 弱权重 + 铭文150 加成
         × 区服系数（安卓Q > iOS）
```

**因子画像**：F1 外观（典藏主导）> F3（限定返场不确定）> F2（战力标衰减快）> F4（点券余额次要）。

**分段与交互**：**切分点 = 有无典藏**（跨段回归失效最严重的游戏）；交互 = 典藏数 × 全英雄（顶配信号）。

**陷阱与话术**："贵10便宜"（接近 V10）是性价比话术；限定皮肤"返场次数"决定价值档——需返场事件库；安卓/iOS 与 Q 区/微信区四分域。

**数据可得性**：卡片字段待实测；皮肤计数/典藏数主要靠标题抽取 [抽]。

### 3.2 和平精英（10011）——"标题即资产清单"型

**定价逻辑推理**：交易猫商品标题自述"载具15升级枪13粉装5尾迹16枪皮122"——**卖家已经用计数资产清单定价**，说明市场对"计数定价"有共识，结构化抽取收益最大。档位规律：**升级枪**（可强化特效枪）独立高价档（成长性资产）；**车皮（载具皮肤）均价 > 枪皮**（展示频率与稀缺度）；军需套装 > 散件；粉装/红装 = 装备稀有度层；尾迹/热力/印记 = 收藏分体系（平台/社区有"收藏分"概念 → 计数加总特征）。无敌战神弱（赛季重置律）。

**估值算式骨架**：
```
预测价 = Σ升级枪 × 单价(高) + Σ车皮 × 单价 + Σ军需套装 × 单价 + 枪皮数 × 均价(低)
         + 粉装/红装/尾迹/热力/印记 计数加成 + 历史段位 × 弱权重
```

**因子画像**：F1 外观主导（几乎全部）> F3（绝版军需）> F4 ≈ F2。

**分段与交互**：切分 = 有无升级枪/限定车皮；交互弱——近似可加模型。

**陷阱与话术**："绝版军需"清单随赛季膨胀；段位号陷阱（只练段位无收藏 = 地板）。

**数据可得性**：pxb7 卡片字段待实测；查证术语表（载具/升级枪/粉装/尾迹/热力/印记）直接做抽取词表。

### 3.3 无畏契约（10148）——"纯皮肤市场"基准型

**定价逻辑推理**：**段位每赛季重置 → 段位价值 ≈ 0**（查证"皮肤 > 段位"）→ 全部价值压在永久皮肤上，是"赛季贬值律"的最纯净样本（对照组价值：用它与王者对比验证衰减处理）。限定皮肤不可返场预期 → F3 强；**近战刀皮是最高档**（文化符号 + 全对局展示）→ 单列档位；辐能余额 = direct 型账面资产（点券直购皮肤）→ 最接近 1:1 折算的市场。查证价位：入门皮肤号 300–800 元。违规记录/实名绑定 = 主要折价（查证）。

**估值算式骨架**：
```
预测价 = Σ限定套装 × 档位价 + 刀皮 × 高档系数 + 传说皮肤计数 × 均价 + 辐能 × 0.9（近似账面）
         + 特工解锁加成 × 违规/实名折价（段位不进模型）
```

**因子画像**：F1 > F3 > F4；F2 ≈ 0（罕见）。

**分段与交互**：切分 = 有无刀皮/冠军赛套装；交互弱。

**陷阱与话术**："冠军赛套装"赛事限定与普通限定分档；VP 消耗记录。

**数据可得性**：卡片字段待实测；手游版（154999114350603）同构接入。

### 3.4 穿越火线系（CF 10039 / CF手游 10033）——"直购账面"型

**定价逻辑推理**：英雄级武器为**充值直购**（888–1000+ 元/把，历史价格稳定公开）→ 获取成本透明 → 市场价 ≈ 英雄级数量 × 直购价 × 稳定折扣——是 direct 机制的最干净样本（同瓦的辐能、更强）。王者级武器更高档。段位弱。**数据可得性可能最好**：按"把数"计价的共识强，标题常见"N 英雄"格式。

**估值算式骨架**：`预测价 = Σ英雄级 × 直购价 × 0.4–0.6 + 王者级 × 更高档 + 其他皮肤计数 × 均价 + 点券余额 × 0.9`（待校准）。

**因子画像**：F1（英雄级）> F4 > F3（早期绝版）> F2 ≈ 弱。

### 3.5 APEX / 永劫无间 / PUBG / CODM / 逆战未来——模板内个体差异

- **APEX（10050）**：**传家宝（Heirloom）**是最强锚（保底期望成本极高、不可交易获得）→ 单品定价主导；传说皮肤计数次要；段位弱。风险：封号争议（外挂误封）→ 平台验号重要。
- **永劫无间（10023）**：红皮 > 金皮（武器/时装双轨），联动限定（如动漫联动）溢价；段位弱。
- **PUBG（10021）/ CODM（10052）**：限定套装/神话武器档位计数 + G币/CP 余额账面折算；CODM 的 Mythic > Legendary 档位（英文词抽取）。

## 4. 收集结构型

### 4.1 火影忍者手游（10032）——"三档忍者分类"型

**定价逻辑推理**：价值集中在忍者收集结构而非皮肤。核心规律是**忍者按获取途径三档定价**：绝版点券 S 忍（不可再获取，最强溢价）> 高招 S 忍（保底累计获取，查证晓鼬/白面带土 40–70 元/只，人气个体更高）> 常驻 S 忍（金币可购，廉价）。查证明确警告话术陷阱："多个 S 忍"多为常驻高招，绝版点券 S 忍"一个没有的号价格大打折扣"——**抽取器必须把 S 忍词表按三档分组**，否则特征被稀释。忍法帖 = 赛季通行证但含绝版内容 → "半绝版档"。通灵/秘卷/时装 = 次要加成。**渠道服 ≈ 官服 1/3**（查证）+ 买家少 → 强制分域。

**估值算式骨架**：
```
预测价 = Σ绝版点券S × 高锚 + Σ高招S(人气加权) × 中锚 + Σ常驻S × 低锚
         + 忍法帖限定进度加成 + 通灵/秘卷/时装加成 + 点券余额 × 0.7
         × 渠道服系数(0.3–0.4)
```

**因子画像**：F3（绝版）> F1（收集）> F4 > F2。

**分段与交互**：切分 = 有无绝版点券 S（有无此档价格中枢完全不同）；交互 = 高招 S × 人气。

**数据可得性**：卡片字段待实测；三档词表是抽取重点。

### 4.2 第五人格（10059）——"单品求和 + 附加项"型（最值得抄进体系的方法论）

**定价逻辑推理**（查证给出完整估价程序）：① **先做单品价值求和**——限定/常驻金皮（稀世时装）、金挂/紫挂（随身物品）逐件按社区估价表计价；② **再叠加附加项**——段位（求生者/监管者双段位，弱）、皮肤总量、**归宿装修**（家园系统资产，独特因子）、账号稳定性。**来源决定稀缺性**：商城金（随时可买，最便宜）< 联动紫 < 限定金（限时不可再购，增值最高）——同为"金皮"价差数倍，词表必须带"来源"属性。**返场打击溢价**（海盗巫医案例）→ 返场事件库直接修改单品价值表。**"不能只数皮肤"**（查证标题）——与绝区零"只数 S 低估"同构：计数不如分档。

**估值算式骨架**：
```
预测价 = Σ(金皮/金挂/紫皮 × 单品价值表 × 来源系数) + 归宿装修加成 + 双段位弱加成
         + 皮肤总量 × 微弱加成 × 渠道/官服系数 × 实名可改系数
```

**因子画像**：F3（限定来源）> F1（金皮/挂件）> F4（回声/碎片）> F2。

**分段与交互**：**单品价值表机制**（item-level price table）是本游戏最大特色 → 词表的 `feature_map` 直接挂单品基准价；返场事件更新单品表。

**陷阱与话术**：商城金冒充限定金；联动限定（动漫联动档）单独追踪。

**数据可得性**：卡片字段待实测；社区估价表（Facebook/Dcard/17173）可导入为单品先验——**社区已有估价表文化，可直接数字化**。

### 4.3 英雄联盟系（10012 / LOL手游 10036）——"来源分档"型

**定价逻辑推理**：皮肤价值几乎完全由**获取来源**决定：至臻（事件兑换）、海克斯限定（宝石抽取，期望成本高）、周年/赛事限定、绝版皮肤 > 普通商城皮肤（几乎不计价）→ 与第五人格"来源分档"同构。皮肤总数只是弱加成；段位弱（赛季重置律）；精粹/点券余额 = 账面折算。（source=domain，待校准。）

**估值算式骨架**：`Σ(至臻/海克斯/限定 × 来源档位价) + 皮肤总数弱加成 + 点券 × 0.9`。

## 5. 养成与外观型

### 5.1 地下城与勇士端游（10025）——"练度标量 + 打造跳变"型

**定价逻辑推理**：**名望值**是官方练度总标量 → 回归的天然基准变量（独此一家有官方单一数值概括账号）。打造深度（增幅/强化）按**期望成本指数跳变**：增幅 10→11→12→13 成功率递减、成本指数增长 → 价格指数级——线性假设失效最严重的维度，必须分档。红字书/黄金书是增幅的成本锚。金币市场成熟（金价公开）→ 资源直接折算。龙袍/天空套 = 绝版外观（F3）。**赃号（黑金追回）是本游戏特有重大风险** → 平台验号核心卖点 → 我们记录验号标签价值大。跨大区转移限制 = 分域。

**估值算式骨架**：
```
预测价 = 基准(名望分段) + Σ增幅装备 × 增幅档位价(指数) + 天空/龙袍 + 年套称号宠物光环
         + 金币 × 金价 × 0.8 × 赃号风险系数 × 跨区系数
```

**因子画像**：F2 练度（名望/打造，主导）> F3 > F4 > F1——**全体系唯一 F2 主导的主流游戏**。

**分段与交互**：名望分段切分；增幅档位独立哑变量（不做线性）。

**数据可得性**：标题高频"名望/增幅 N"→ 抽取友好；卡片字段待实测。

### 5.2 超自然行动组（154643349307491）——"外观主导 + 基地养成"型
