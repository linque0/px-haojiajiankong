# 17 扩展查缺补录功能

定位：扩展 v0.5.6 的使用说明、数据口径与验收记录。日期：2026-10-06。

> 2026-10-06 更新（v0.5.8，[docs/19](19-完整看板查缺补录与下架检测.md)）：本文所述"补录全部"按钮已改为"全选/取消全选"切换（全选后点"补录选中"）；鸣潮查缺口径已按看板列逐列扩展（资源/额外付费商品/区服/发布时间/收藏）；查缺补录区块同步加入完整看板，可由看板发起、扩展领取执行。

## 改动

扩展打开时查询当前已勾选采集目标，每 10 秒更新清单；范围为每个商品的最新快照。
支持按游戏筛选（含查看其他游戏）、每页 10 条、跨页勾选、补录选中和补录全部。
未启用的采集目标只能查看，需先勾选游戏才能补录。空目标沿用现有网关默认任务。

| 游戏 | 关键检查项 |
|---|---|
| 鸣潮、原神 | 等级、黄数、五星角色/武器数量、具名角色链数/命座和武器精炼明细 |
| 火影忍者 | 等级 |
| 三角洲行动 | 等级、烽火等级、战场等级、传说武器/史诗武器/刀皮数量 |
| 其他游戏 | 暂仅等级，筛选游戏时展示检测范围 |

0 是有效值；数量为 0 不要求相应明细。正数对应的名单必须包含有效具名条目，
并与数量匹配；角色重复名字视为无效，重复武器保留。资源和额外付费商品等可选信息
不触发补录。检测命中不保证网站一定公示相应信息，未补齐时保留具体原因。

新增固定接口：`GET /backfill/candidates`（game_id=selected/all/编号、offset、limit），
`POST /backfill/prepare`（范围及 all=true 或 items=[{id,snapshot_round}]），
`POST /backfill/sync`（game_ids）。清单返回完整快照时间、缺失原因及是否可采集。
准备接口重新校验最新候选，在项目串行锁内 CHECKPOINT、关闭连接后复制数据库至
数据库同级 `backups/backfill-时间.duckdb`；备份失败不返回可启动队列。
补录启动/查询/同步消息只接受本扩展 popup.html；准备和同步 HTTP 端点只允许本机来源。
商品 URL 由网关基于库内编号构造，固定为 `https://www.pxb7.com/product/{id}/1`。

扩展复用现有持久化单队列/详情工作标签页，每项携带自己的 snapshot_round；全部补录
按 200 条划分批次串行推进，保留配置的详情间隔。关闭弹窗、SW 休眠后队列仍可继续。
每项同一任务只尝试一次；连续三条失败暂停。验证暂停不消耗当前账号，用户完成验证后
继续。取消保留已入库成果并返回原活动标签页，可重新查询启动。

`/ingest/detail` 的 backfill=true 路径在同一写事务中再次核对最新轮次，已有更新轮次则
返回 latest-snapshot-changed、不写历史行。当前详情中明确采到的资产数量/信息刷新原值；
数量改变或取得新名单时清理旧名单/聚合值，0 数量清除对应名单。没有新值的标量保留
已有值；没有依据填 0。保存补录时间 `_backfilled_at` 和原始详情 DOM/快照轮次元数据，
回执返回落库后重新计算的 complete/missing。原挂牌价、snapshot_at、历史轮次及总行数
保持不变。

每次详情入库调用现有 `sync_game_csv` 更新 `data/analysis/by_game` 该游戏原 CSV，
保留已存在的带日期文件名、鸣潮看板列布局及 UTF-8 BOM，临时文件原子替换。
文件占用或导出错误独立于入库结果，扩展持久保存待同步游戏与原因；点击“重试同步数据表”
仅重新导出数据库，不访问商品页。随后成功导出同一游戏（普通采集或重试）清除提示。

## 使用

1. 网关已重启至新代码。扩展弹窗显示更新提示时，点击“应用扩展更新”并重新打开，确认 v0.5.6。
2. 在“信息查缺补录”选择已勾选游戏或具体游戏，查看缺项。其他游戏先在“采集目标”启用。
3. 勾选记录后点“补录选中”，或点击“补录全部”；备份成功才打开后台详情工作页。
4. 在顶部查看入库、失败、待补齐进度；遇验证在工作页手动完成，再继续原任务。
5. 数据表同步失败时关闭占用 CSV 的软件，点击“重试同步数据表”。未补齐记录仍在清单中。

## 诚实边界

查缺口径只覆盖已支持解析的关键项，不代表所有可选信息均完整；站点未披露、下架或解析器
不支持的内容可能始终无法补齐。价格与轮次保持原值，但资产字段允许采用现在的详情信息；
补录时间与 raw 元数据用于区别时间口径。当前 browser 工具禁止打开 chrome-extension://，
未直接操作真实扩展弹窗或运行新功能的真实站点补录；浏览器验收使用明确标识的离线模拟界面，
队列与数据库行为由实际模块的离线回归验证。浏览器中旧扩展需应用更新后使用。
